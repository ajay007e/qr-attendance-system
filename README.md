# Attendance Management System

Attendance management platform.

## Tech Stack

### Backend

- Node.js
- Express
- TypeScript
- MySQL

### Frontend

- Next.js
- TypeScript
- Tailwind CSS

---

## Project Structure

```
backend  -> API server
frontend -> Web application
database -> SQL scripts
```

---

## Backend Setup

```bash
cd backend

pnpm install

cp .env.example .env

pnpm dev
```

API runs:

```
http://localhost:5000
```

---

## Frontend Setup

```bash
cd frontend

pnpm install

cp .env.example .env.local

pnpm dev
```

Frontend runs:

```
http://localhost:3000
```
